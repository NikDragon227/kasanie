# Юридическая готовность к тихому запуску

Это рабочий перечень для владельца сервиса. Он не заменяет проверку профильным юристом: фактические процессы, подрядчики, сроки хранения и модель платежей должны совпадать с опубликованными документами.

## Уже реализовано в продукте

- Публично доступны Политика конфиденциальности, Пользовательское соглашение и Правила для организаторов.
- При регистрации фиксируются версия документов, факт и время их принятия.
- Публичные реквизиты оператора и контакт по персональным данным берутся из production-переменных окружения; не хранятся в Git.
- Пользователь может направить обращение по персональным данным на публичный адрес поддержки.

## До реального публичного запуска

- [ ] Владелец утверждает редакцию документов и дату вступления в силу.
- [ ] Сверить фактические цели, перечни данных, сроки хранения, процессы удаления и список подрядчиков с Политикой.
- [ ] Проверить размещение БД и резервных копий, а также договорные условия подрядчиков, которые получают персональные данные.
- [ ] Подать уведомление об обработке персональных данных в Роскомнадзор через [официальный портал](https://pd.rkn.gov.ru/operators-registry/notification/form/), если для деятельности нет законного исключения.
- [ ] Зафиксировать внутренний порядок обработки обращений субъектов ПДн, удаления данных и реагирования на инциденты.
- [ ] Согласовать с юристом модель оплаты, возвратов и роли площадок/организаторов до подключения платежей.

## Регулярно после запуска

- [ ] Пересматривать документы при изменении данных, подрядчиков, аналитики, способов оплаты или состава обрабатываемых данных.
- [ ] Проверять, что новая версия документов отражена в регистрации и сохранена в истории согласий.
- [ ] Проверять обращения по персональным данным и инциденты по внутреннему регламенту.
