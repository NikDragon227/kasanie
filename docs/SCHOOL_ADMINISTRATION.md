# Управление школами администратором

В разделе «Администратор → Школы» доступны «Управлять школой» и «Сменить владельца».
Школа выбирается через параметр `school` и сохраняется при переходе между обзором,
составами, тренерами, игроками и настройками. Администратор видит также заблокированные
школы и отключённые команды, которые можно восстановить через редактирование.

## Права и операции

- Администратор платформы управляет существующими школьными операциями без членства
  в конкретной школе. Права обычных пользователей на чужие школы не расширены.
- `PUT /api/admin/schools/{schoolId}/owner` принимает `ownerEmail` и необязательный
  `expectedOwnerEmail`. Проверка ожидаемого владельца защищает от устаревшей формы.
  Старое членство владельца отключается и меняет тип; назначения тренером сохраняются
  отдельно. Глобальная роль SchoolOwner снимается только при отсутствии других
  активных владений. Для аккаунта без пароля возвращается одноразовое приглашение,
  которое администратор передаёт лично; автоматическое письмо не отправляется.
- `PUT /api/admin/schools/{schoolId}/coaches/{userId}/status` отключает членство
  тренера и удаляет его назначения во всех командах этой школы. При восстановлении
  доступа назначения необходимо восстановить отдельно. Владельца нельзя отключить
  этим действием: для него используется смена владельца.
- Приглашение тренера и назначения в команды используют существующие школьные API.
  Администратор может подключить существующего тренера нескольких школ.
- Тактика доступна администратору через школьный API; цикл — через
  `PUT /api/admin/schools/{schoolId}/teams/{teamId}/cycle`. Принадлежность команды
  школе проверяется сервером.
- Изменения владельца, статуса тренера, тактики и цикла записываются в аудит.

Смена владельца и перемещение игрока выполняются в serializable-транзакции на
PostgreSQL; конфликты записи возвращают 409. Новых таблиц для этих изменений нет.

## Контекстные действия игрока

В обзоре состава тренера меню открывается правым кликом, Shift+F10 либо кнопкой ⋯.
Перемещение разрешено между назначенными тренеру активными составами одной школы.
Старая запись состава и её статистика сохраняются; индивидуальный тренировочный
план переносится, игрок исключается из наставничества исходного состава. Если номер
занят в новом составе, он сбрасывается для отдельного назначения.

Отдых, интенсивность и комментарий сохраняются точечным обновлением тренировочного
плана с увеличением его версии. Во вкладке отдыха показываются только игроки с
постоянным отдыхом или неистёкшей датой. Сравнение и поиск похожих игроков ограничены
доступными тренеру активными составами; отсутствующие оценки навыков не подставляются.
Обычные заметки сохраняются через существующий API отчёта игрока.
