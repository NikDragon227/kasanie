# Детерминированный алгоритм тренировочного плана

Сервис `ITrainingPlanGenerator` / `TrainingPlanGenerator` не использует AI или ML и одинаково отвечает на одинаковые входные данные.

1. Backend нормализует каждый тест по возрастной DEMO-шкале в диапазон 0–100. Направление теста учитывается: для времени меньше лучше, для количества/дистанции — больше лучше.
2. Из шести категорий выбираются две с минимальным score.
3. Позиция добавляет приоритет: вратарь → ловкость, защитник → передачи, нападающий → удары, остальные → контроль мяча.
4. Активные упражнения получают вес: слабая категория — 5, позиционная — 3, общая — 1.
5. На неделю создаются три дня через день, по четыре упражнения. В одном дне одно упражнение не повторяется.
6. План и причина генерации сохраняются в PostgreSQL; предыдущий активный план архивируется после нового тестирования.

Текущая версия проста намеренно. Настройка веса, нагрузки по возрасту, медицинские ограничения и научная валидация норм — отдельный последующий этап. Алгоритм покрыт xUnit-тестами.
